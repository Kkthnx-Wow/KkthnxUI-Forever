# KkthnxUI Forever

A clean, minimalist interface replacement for World of Warcraft Forever.

This is the Forever edition of KkthnxUI. It only supports the Forever client (Interface 16001) and is developed on its own, apart from the Retail edition.

## Install

Copy the `KkthnxUI` folder into `World of Warcraft\_forever_\Interface\AddOns\`.

Log in and type `/kk` to open the options.

## What it covers

- Unit frames for player, target, target of target, pet, focus, boss, party and raid
- Swing timer, shaman totems, PvP flag icon and hunter pet happiness
- Castbars with interrupt colouring
- Action bars with pet, stance and possess bars
- Player buffs and debuffs, unit frame auras and nameplate auras
- Nameplates
- Bags and bank with categories, search and a bag bar
- Micro menu, minimap, tooltips, chat, world map tweaks and a quest tracker skin
- Character and inspect frame skin with slot item levels and enchant warnings
- Automation and quality of life modules, each one optional

## Commands

- `/kk` opens the options
- `/kk test` shows every unit frame with your own data so you can position them
- `/kkdebug` lists the debug streams

## Reporting problems

Open an issue and include your build number and the error text. An error catcher such as Sentinel makes that easy.
